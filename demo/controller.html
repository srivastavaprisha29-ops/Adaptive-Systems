Resource-aware feature controller

An interactive, illustrative model of how runtime resource conditions can influence intermediate feature width and numeric precision. No actual AI inference is being performed here.

This controller uses fictional thresholds to illustrate a heuristic. Real controller inputs require measured telemetry and calibration.

4 · What should the experiment measure?

Accuracy/quality, median/p95 end-to-end latency, throughput, allocated and peak memory, measured energy per inference, and switching/monitoring overhead. Compare the controller to both full and best-feasible static configurations.

No external API calls, data collection or model execution. All values are teaching examples.
